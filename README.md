# AutoVideo —— Edge 浏览器自动刷视频插件

在 **抖音、快手、TikTok、Instagram、Facebook** 上自动浏览短视频：
打开插件点击「开始」，每个视频停留指定秒数后自动切换到下一个，支持静音、随机间隔等设置。

基于 Manifest V3，同时兼容 Chrome / Edge / 其他 Chromium 内核浏览器。

## 功能

- ✅ 一键开始 / 停止，工具栏角标实时显示运行状态
- ✅ **网页悬浮条**：置顶显示运行状态、已刷数量，可直接开始/停止、调节停留时长；可拖拽、可折叠、可关闭（弹窗里可重新开启）
- ✅ 每个视频停留时长可调（3–120 秒，默认 15 秒）
- ✅ 「视频播完立即切换」：看到结尾不用等
- ✅ 静音播放，适合后台挂机
- ✅ 随机间隔（±15% 抖动），浏览节奏更像真人
- ✅ 标签页隐藏时自动暂停，切回来自动恢复
- ✅ 全局快捷键开关：`Alt + Shift + A`（可在 `edge://extensions/shortcuts` 修改）
- ✅ 统计本次已刷视频数量与时长（弹窗底部显示当前版本号）

## 支持平台与切换方式

插件会**自动识别页面形态**并选择合适的切换方式：

- **全屏播放页**（单个视频占满屏幕）：点击「下一个」按钮 → 模拟键盘 ↓ → 滚动
- **信息流页面**（抖音精选、瀑布流、主页等）：滚动 → 模拟键盘 ↓ → 点击按钮

即使平台改版导致按钮选择器失效，也会自动退化为键盘/滚动方式继续工作：

| 平台 | 全屏页首选 | 信息流首选 |
| --- | --- | --- |
| 抖音 douyin.com（含抖音精选） | 点击「下一个」按钮 | 滚动加载下一个视频 |
| 快手 kuaishou.com | 点击「下一个」按钮 | 滚动加载下一个视频 |
| TikTok tiktok.com | 点击浏览页右侧「下一个」按钮 (`data-e2e="browse-next"`) | 滚动 |
| Instagram instagram.com | 点击 Reels「Next」按钮 | 滚动 |
| Facebook facebook.com | 点击 Reels「Next video」按钮 | 滚动 |

> 键盘模拟会把 `keydown / keypress / keyup` 事件（带完整 keyCode）派发到页面各层，并先聚焦视频元素，最大程度模拟真实按 ↓ 键的效果。

## 安装（Edge）

1. 打开 `edge://extensions`
2. 打开右上角「**开发人员模式**」开关
3. 点击「**加载解压缩的扩展**」，选择本文件夹（`AutoVideo`）
4. 打开任意支持的平台页面，点击工具栏上的 AutoVideo 图标 → 点「▶ 开始自动刷」

> Chrome 用户：打开 `chrome://extensions`，同样开启开发者模式后加载。

## 使用说明

- **开始后**：当前播放的视频停留满设置秒数后自动切到下一个；视频提前播完会立即切换
- **网页悬浮条**：页面右上角默认显示，可直接看状态和操作；按住拖动可换位置，点「—」折叠成小圆点，点「✕」关闭（在插件弹窗勾选"网页悬浮条"可重新显示）
- **快捷键**：`Alt + Shift + A` 在当前标签页快速开始 / 停止
- **手动暂停视频**：暂停超过 8 秒会自动切换到下一个视频；如需彻底暂停请点「⏸ 停止」
- **设置自动保存**：间隔、静音等选项保存在浏览器同步存储中，下次打开仍是上次的配置

## 常见问题

- **打开抖音是"抖音精选"页面**：这是抖音网页版的默认信息流（瀑布流卡片）页面，插件会自动采用"滚动 + 键盘 ↓"策略来刷视频；未登录时会弹出登录引导，登录后即可自动浏览
- **提示「未检测到视频」**：说明当前视口内没有视频元素（如信息流中滚到了图片帖、或视频还在懒加载）。插件会保持运行并每 6 秒滚动一次尝试刷出视频，不会自动停止
- **视频重复播放、已刷计数虚增**：这是 1.1.5 之前版本的已知问题（短视频循环播放被误判为新视频，导致计时永不到期）——请升级到 1.1.5 并重新加载扩展
- **刷着刷着不动了**：常见原因——① 滚动到了页面底部（已无新内容）：悬浮条会显示"已到达页面底部"，插件每 30 秒自动重试一次，**手动向上滚动即可恢复**；② 当前切换方式失效（如平台限制按钮）：插件会自动切换备用方式（点击↔滚动互换），连续 2 次未生效即自动切换，悬浮条显示"切换受阻"；③ 视频被手动暂停（8 秒后自动切换）；④ 网络慢导致新视频加载不出来（会自动重试）。若长时间卡在同一处，可刷新页面或点「⏸ 停止」后重新开始
- **平台改版后切不动**：插件会自动退化为按键/滚动方式，一般仍能工作；若长时间失效可反馈更新选择器
- **角标/悬浮条不显示**：刷新页面后重新点击开始；悬浮条如被关闭，可在插件弹窗中重新勾选开启

## 合规提示

本插件仅用于**个人正常的浏览体验**（如后台挂机看视频、自动播放下一条）。
请遵守各平台的服务条款，**不要**用于刷播放量、制造虚假互动等行为，否则账号可能被平台限制。
插件刻意**不包含**自动点赞、自动评论、自动关注等互动功能。

## 文件结构

```
AutoVideo/
├── manifest.json      # MV3 清单：权限、域名匹配、快捷键（版本号唯一来源）
├── background.js      # 后台服务：快捷键 + 工具栏角标
├── content.js         # 核心引擎：平台识别、视频检测、自动切换、网页悬浮条
├── popup.html/css/js  # 弹窗控制面板
├── icons/             # 插件图标（16/32/48/128）
├── tools/make-icons.ps1  # 图标生成脚本（重新生成用）
└── DEVELOPER.md       # 开发者文档（架构、消息协议、扩展指南、版本管理约定）
```
